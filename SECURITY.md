# Security

Please report vulnerabilities privately, not in a public issue.

- Use GitHub's **Report a vulnerability** button on this repo's Security tab, or
- email support@automatedclientacquisition.com with "Security" in the subject.

Include what you found, how to reproduce it and what an attacker could do with it. We reply within
three working days and keep you updated until it is fixed. We credit reporters who want it once a
fix has shipped.

Fixes go to ACA Cloud first, then to this repo. Self-hosted installs should update when a release
mentions a security fix.

In scope: this code and ACA Cloud (`*.automatedclientacquisition.com`). Out of scope: denial of
service, social engineering, and findings that need a compromised device or admin account.
