# Code of conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, criticise code rather than people, and keep discussions on
topic. Harassment, personal attacks and discriminatory language aren't welcome in issues, pull
requests, discussions or anywhere else this project lives.

Report problems to support@automatedclientacquisition.com. Reports are read by the maintainers and
kept confidential. Maintainers may remove content and block people who break these rules.
